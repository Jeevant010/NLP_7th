LAB ASSIGNMENT-2 DATA FILES

Use the files in plain/ for the Plaintext Corpus.
Use the files in categorized/ for the Categorized Corpus.
Brown, Inaugural, Reuters, and UDHR are downloaded separately through NLTK.

The categorized folder structure is category-based and can be loaded with
CategorizedPlaintextCorpusReader using a pattern such as r'(\w+)/.*'.
